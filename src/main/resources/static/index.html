Crash one node mid-commit — another node finishes it

Every node shares PostgreSQL, Artemis and the LogCloud transaction log in PostgreSQL. Crash a node after the XA prepare: the node that leads recovery commits what it left behind — no restart, no local disk.

💀 All nodes are down. Start one with ./mvnw spring-boot:run.
